# Producto y alcance

## Objetivo

Crear un constructor sencillo para personas que necesitan publicar una página personal o comercial sin aprender diseño web ni editar código. El producto debe limitar las decisiones disponibles para que una página se vea coherente sin ofrecer la complejidad de un editor visual completo.

## Usuarios iniciales

- Profesionales que quieren un portafolio o curriculum público.
- Personas que necesitan una página personal con presentación, experiencia y contacto.
- Pequeños negocios que más adelante podrán usar plantillas de restaurante o landing comercial.

## Flujo principal

1. El usuario crea una cuenta.
2. Crea un proyecto desde una plantilla de portafolio.
3. Edita el nombre, descripción, colores e imágenes.
4. Añade, elimina y reordena bloques.
5. Guarda un borrador y revisa la vista previa.
6. Publica una versión en una subruta administrada.
7. Consulta los mensajes recibidos desde el bloque de contacto.
8. Opcionalmente exporta el proyecto como sitio Astro.

## Qué debe sentirse sencillo

- El usuario trabaja con secciones completas, no con elementos HTML individuales.
- Cada bloque expone pocas propiedades que tengan un resultado visible y predecible.
- El sistema ofrece valores iniciales razonables y una plantilla completa desde el primer paso.
- El contenido se puede cambiar sin perder la composición del diseño.
- El usuario distingue con claridad entre borrador y versión publicada.

## MVP

El MVP incluye:

- Cuenta individual y varios proyectos por usuario.
- Plantilla inicial de portafolio/CV.
- Editor por bloques con reordenamiento.
- Guardado automático de borrador.
- Publicación en subruta administrada.
- Subida y reutilización de imágenes.
- Bloque de contacto con bandeja interna.
- Exportación de un proyecto Astro.

## Fuera del MVP

- Edición libre de HTML, CSS o JavaScript.
- Colaboración entre usuarios.
- Dominios personalizados y subdominios.
- Tiendas, pagos y reservas.
- Analítica avanzada.
- Formularios enviados por email.
- Sistema completo de temas creados por usuarios.

## Éxito de la primera versión

El flujo se considera validado si una persona puede crear y publicar un portafolio sin ayuda técnica, cambiar el orden de sus secciones, reemplazar una imagen y encontrar un mensaje enviado desde la página pública.

Las métricas que conviene medir después del lanzamiento son:

- Tiempo desde el registro hasta la primera publicación.
- Porcentaje de proyectos que llegan a publicar.
- Cantidad de bloques editados por proyecto.
- Porcentaje de usuarios que regresan para modificar un sitio.
- Cantidad de exportaciones Astro solicitadas.
